# 糖糖日记｜验收清单

本清单适用于 Codex 提交前和 GitHub Pages 发布后。勾选表示实际完成；没有测试设备就标记“未验证”。

## A. 部署与资源

- [ ] 仓库设置正确，GitHub Pages 已经发布，且返回实际最终网址。
- [ ] 在网址 `https://用户名.github.io/仓库名/` 能加载完整首页。
- [ ] `index.html`、CSS、JS、SVG、PNG、manifest、Service Worker 在项目子路径均正常，无 404。
- [ ] 不是空白页面；浏览器控制台没有应用自身的严重错误。
- [ ] GitHub Actions 显示部署成功，仓库链接与提交 SHA 可追溯。
- [ ] iPhone Safari 可以访问；“添加到主屏幕”后名称为「糖糖日记」，图标正确。
- [ ] 已安装 PWA 的离线重新打开与更新后的缓存可正常工作。

## B. 首次使用与基础记录

- [ ] 全新浏览器进入时 **0 条真实记录**，没有虚构奶量、黄疸或体温。
- [ ] 可填写宝宝昵称、准确出生时间，日龄与黄疸记录中的生后小时数可更新。
- [ ] 首页只有喂奶、尿布、黄疸、体温四个快捷入口，睡眠不显示。
- [ ] 首页四个入口沿用原来的卡片大小，显示图标、名称及最近一次的关键内容和时间；喂奶入口先显示奶量折线图，再显示具体记录，底部保留添加按钮。保存后回到该类列表，最新记录排列在前。
- [ ] 瓶喂填写 45ml 可以保存，首页奶量和次数同步改变。
- [ ] 母乳增强剂仅记录是否添加，勾选后无需填写品牌或剂量即可保存；新建下一次喂奶默认不添加。旧记录中的增强剂明细在 JSON 和 CSV 中继续保留。
- [ ] 尿布的小便、大便、都有均可快速保存；补记时间有效。
- [ ] 黄疸 TcB / TSB、数值、原始单位、时间、机构正常保存，不给出风险判定。
- [ ] 黄疸支持一次或多次测量，读数可增减，平均值按已填次数实时计算，空白不计入；旧单次数值、四次读数和导入批次均可编辑并再次备份恢复。
- [ ] 体温、体重、实际用药信息可新建、编辑。
- [ ] 记录时间线按时间显示，可筛选、删除、撤销。
- [ ] 网页刷新后，先前记录与个人偏好不丢失。
- [ ] 夜间模式切换后字体和背景对比度可读。

## C. JSON 备份与恢复（最高优先）

- [ ] 完整 JSON 导出时可以从 iPhone 系统分享保存到“文件”或 iCloud Drive。
- [ ] JSON 包含版本号、宝宝资料、所有记录及必要字段；不将文件上传到其他网络服务器。
- [ ] 从同一份 JSON 导入，恢复后记录数量、奶量、增强剂信息、黄疸原始单位等一致。
- [ ] 新格式 `tangtang-journal-backup` 可以导入。
- [ ] 旧格式 `xiaoman-journal-backup` 可以导入。
- [ ] 无效文件、重复记录 ID、损坏 JSON 不会修改原有数据。
- [ ] 导入前提示当前记录数、备份记录数和将覆盖的后果；取消后旧数据仍存在。
- [ ] 导入完成后直接显示恢复后的记录，刷新后仍存在。
- [ ] 用户知道网页本身不自动同步 iCloud。

## D. CSV 数据导出

- [ ] CSV 带 UTF-8 BOM，Excel 可正常识别中文。
- [ ] 列出记录时间、类型、奶量、母乳增强剂的实际用量、尿布类型和状态、黄疸方式/单位、体温、体重、实际用药及备注等明细。
- [ ] 文字包含逗号、双引号或换行时仍不破坏列结构。
- [ ] 对以 `=`、`+`、`-`、`@` 等可疑字符开头的文字采取 CSV 公式注入防护。
- [ ] 明确 CSV 是用于查看/打印，不提供 CSV 全量恢复承诺。

## E. 手机细节与隐私

- [ ] iPhone Safari 竖屏、小屏下底部导航与输入框不遮挡。
- [ ] 记录弹层滑动和键盘弹出后可以点到保存按钮。
- [ ] 底部安全区、状态栏与夜间模式显示正常。
- [ ] 不依赖登录、手机号、微信实名认证、云数据库或在线 API。
- [ ] GitHub 仓库与网站资源中没有真实宝宝信息、隐私记录、密钥或导出的备份文件。
- [ ] 从旧域名到新域名的迁移说明已交付；提醒用户旧数据不会自动跨域出现。

## 验收输出格式

报告：通过项目数 / 未通过项目数 / 未验证项目数，列出问题与修复措施；另给出 GitHub Pages 地址、GitHub 仓库地址、提交 SHA 和 iPhone 真机验证结论。
