# 数据隐私、备份与旧记录迁移

## 数据放在哪里？

糖糖日记把宝宝资料、喂奶、尿布、黄疸、体温、体重和实际用药记录保存在**打开网页的设备浏览器 IndexedDB** 中。GitHub Pages 只负责提供 HTML/CSS/JavaScript 文件，不接收宝宝的记录。

但请牢记：

- 网页可以公开访问，不等于记录公开；记录仍只保存在当前浏览器的本地存储。
- 这也不意味着绝对不会丢失：浏览器清理数据、系统清理网站存储、换机、Safari 与主屏幕网页存储隔离等都可能影响记录。
- 此设计没有自动云备份，不会自动同步到 iCloud。
- 不能把该网页作为宝宝健康资料的唯一备份。

## 每次备份

1. 在糖糖日记打开“设置”。
2. 找到“数据导入与导出”。
3. 点击“导出完整数据（JSON）”。
4. 在 iPhone 分享菜单中选择“存储到文件”，可选 iCloud Drive 中易找的文件夹。若浏览器走下载流程，请在 Safari 的“下载”或“文件”应用的下载文件夹中查找。
5. 打开“文件”应用，确认 JSON 文件确实存在。仅点击分享菜单不代表已经保存。

CSV 适合用 Excel 查看；需要原样恢复时应使用 JSON。

## 从当前 ChatGPT 私有原型搬到 GitHub Pages

**重要：不同网站域名拥有彼此隔离的浏览器数据。** 原型中的记录不会自动出现在 GitHub Pages 新网址里。

1. 先在仍能登录的**旧站点**打开设置，导出完整 JSON。
2. 确认文件保存成功，再打开 Codex 部署的新 GitHub Pages 地址。
3. 若平常要从主屏幕进入，先在 Safari 为新站选择“共享 → 添加到主屏幕”，然后点新图标打开。再在“设置 → 导入备份数据（JSON）”从“文件”应用选刚才的备份。这样可避免备用 Safari 标签页与主屏幕 App 的存储不同。
4. 确认导入覆盖提示，检查时间线、喂奶次数、奶量、增强剂、黄疸等是否一致。
5. 再从新站导出一份 JSON，验证新站也能可靠备份。
6. 在新站稳定运行之前，不要主动清除旧站的本机数据。

## 公开 GitHub Pages 的边界

GitHub Free 下使用公开仓库托管网页是常见方案，网页代码和站点地址可以被外人看到。不要把真实医疗数据、身份证信息、家庭住址、密码、API Key 或 JSON/CSV 备份加入 Git 仓库。保护数据依赖**不上传数据到仓库、只做本机记录、按需手动备份**，而不是依赖网址“没人知道”。

如果以后必须做到“只有妈妈登录才能使用”“多个设备自动同步”，那是另一个产品设计和托管方案，需先重新评估隐私、账户和数据服务。
